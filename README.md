# Ұлы дала — Моңғол империясының ізі

Қазақ тіліндегі кинематографиялық тарихи сайт. React, Vite, TypeScript, Tailwind CSS, GSAP және ScrollTrigger қолданылды.

Іске қосу:

```sh
npm install
npm run dev
```

Өндірістік нұсқаны дайындау:

```sh
npm run build
npm run preview
```

Дайын статикалық сайт `dist/` қалтасында. Бөлек серверлік қосымша, дерекқор немесе тіркелу жүйесі жоқ.

Барлық сурет `public/images/` ішінде сақталған. Қаріптер Google Fonts арқылы жүктеледі; байланыс болмаса жүйелік serif және sans-serif қаріптері қолданылады. Instrument Serif қазақ кириллицасын қамтымағандықтан, қазақ мәтініне Cormorant Garamond қосымша қарпі берілді.

Хронология түймесі барлық он тарауды ашады. Картадағы жылдар мен әскер бөлімдерінің түймелері айналдыру позициясын өзгертеді. Ұлыстар мен жорық бағыттары таңдау арқылы ерекшеленеді. Жүйедегі анимацияны азайту параметрі қосылса, сахналар статикалық оқылатын көрініске ауысады.

Саяси шекаралар мен жорық бағыттары — оқу мақсатындағы шартты сызбалар. Қазіргі Қазақстан шекарасы тек салыстыру үшін көрсетілді. Тарихи дереккөздер мен сурет сілтемелері сайттың төменгі бөлігінде берілген.

Сайт мекенжайы: https://waxyfx.github.io/M0ngoly/

`main` тармағына өзгеріс жіберілгенде GitHub Actions сайтты жинап, GitHub Pages арқылы жариялайды. Жергілікті алдын ала қарау мекенжайының соңына `/M0ngoly/` жолын қосыңыз.
